# Red de Apoyo

Prototipo móvil de una aplicación de apoyo para personas que viven situaciones de violencia intrafamiliar en Chile.

## Estado actual

Este repositorio contiene un prototipo educativo. El botón de ayuda es demostrativo: **no envía alertas, no comparte ubicación y no contacta automáticamente a servicios de emergencia**.

## Contactos en Chile

- Carabineros: 133
- SAMU / ambulancia: 131
- PDI: 134
- Orientación por violencia contra las mujeres: 1455

Verifica los números, horarios y canales oficiales antes de publicar la aplicación. Si existe peligro inmediato, usa los canales oficiales de emergencia cuando sea seguro hacerlo.

## Seguridad y privacidad antes de un lanzamiento

- No almacenar ubicación ni información sensible sin necesidad, consentimiento informado y medidas de protección adecuadas.
- Considerar que una persona agresora podría revisar el teléfono, las notificaciones, el historial o el uso de la app.
- No prometer confidencialidad absoluta ni respuesta policial automática.
- Antes de habilitar alertas reales, coordinar formalmente con servicios pertinentes, evaluar riesgos, revisar obligaciones legales y realizar pruebas de seguridad y accesibilidad.

## Tecnología prevista

React Native, Expo y TypeScript.

## Desarrollo

Instala Node.js LTS y luego ejecuta:

```bash
npm install
npx expo start
```
